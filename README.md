# CourseApplication

Simple Application Form built with Angular 8 and .Net Core.

## Getting Started

These instructions will get you a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

* [Npm](Comes with Node.js: https://nodejs.org/en/#home-downloadhead)
* [SQL Server]
* [Visual Studio 2019]

### How to run

First, check the NPM version and install Angular CLI. Type these commands in the command line:

```
npm -v
npm install -g @angular/cli
```

Next, build and run the application from inside VS.
Navigate to [https://localhost:44346/] to view the app.

##### Built With

* Angular 8
* .NET Core 3.1
